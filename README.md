# 📦 Inventory Management System

A web-based Inventory Management System developed using Python Flask, SQLite and HTML/CSS.

## 📌 Project Overview

The Inventory Management System is designed to help manage products, stock levels and inventory transactions digitally.

The system allows an administrator to add, update, delete and search products. It also provides Stock In, Stock Out, transaction history and low-stock alerts.

## 🚀 Features

- 🔐 Admin Login
- 📊 Dashboard
- 📦 Product Management
- ➕ Add Products
- ✏️ Edit Products
- 🗑️ Delete Products
- 🔎 Search Products
- 📥 Stock In
- 📤 Stock Out
- 🔄 Transaction History
- ⚠️ Low Stock Alerts
- 📱 Responsive Interface

## 🛠️ Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- Flask-Login
- SQLite
- HTML
- CSS
- Jinja2
- Git & GitHub
